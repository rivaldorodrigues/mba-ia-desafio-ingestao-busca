# AGENTS.md

This file provides guidance to agents when working with code in this repository.

## Project

RAG (Retrieval-Augmented Generation) CLI: reads a PDF, chunks it, stores embeddings in PostgreSQL/pgVector, and answers questions based exclusively on the document via LangChain.

**Stack**: Python 3.12, LangChain, PostgreSQL + pgVector, OpenAI or Gemini (provider choice at runtime via `.env`).

---

## Commands

```bash
# Dependencies
uv sync

# Run tests (skips integration by default)
uv run pytest
uv run pytest tests/test_file.py::test_name -v   # single test
uv run pytest -m integration                       # integration tests only

# Lint / format
uv run task lint        # ruff check
uv run task format      # ruff format
uv run task fix         # ruff check --fix
uv run task typecheck   # basedpyright --level error app/
uv run task check       # lint + compile + typecheck

# Start database
docker compose up -d    # provisions pgvector extension automatically

# Ingestion and chat (run in order)
python src/ingest.py
python src/chat.py
```

> `requirements.txt` is auto-generated by `uv export`. **Never edit it manually** — use `uv add` / `uv remove`.

---

## Critical Behaviours

- **Ingestion is not idempotent**: re-running `src/ingest.py` on the same collection creates duplicates. To re-ingest from scratch, destroy the volume: `docker compose down -v && docker compose up -d`.
- **The model is context-only**: the RAG prompt in `src/search.py` forbids the LLM from using external knowledge. Any question outside the ingested PDF returns a fixed "no information" message.
- **Similarity search retrieves top 10 chunks** (`k=10`) to build the context for the LLM.
- **Provider choice is env-driven**: fill in only `OPENAI_*` keys _or_ `GOOGLE_*` keys in `.env`; leave the unused provider blank.
- **DATABASE_URL** must use the psycopg3 scheme: `postgresql+psycopg://...` (not `psycopg2`).

---

## Architecture

```
src/ingest.py  → loads PDF_PATH → chunks (1000 chars / 150 overlap) → embeddings → PGVector
src/search.py  → PROMPT_TEMPLATE (Portuguese) + PromptTemplate → formats question with retrieved context
src/chat.py    → CLI loop → calls search_prompt() → streams answer
```

**Entry points**: `python src/ingest.py` then `python src/chat.py`.

## Code Style

- **Formatter**: `ruff format` — double quotes, 4-space indent, 140-char line limit.
- **Linter**: `ruff check` with pycodestyle, pyflakes, isort, bugbear, comprehensions, pyupgrade, simplify.
- **Type checker**: `basedpyright` at `--level error` (stricter than standard pyright).
- **Isort**: first-party = `["app"]`; section order: future → stdlib → third-party → first-party → local.
- **Ignored rules** (intentional): `E501`, `B008` (FastAPI defaults), `SIM112` (lowercase env vars — IBM Cirrus), `N803/N806/N815` (camelCase API entities).
- **Docstrings**: Google-style for all public functions and classes.
- **Type hints**: required on all function signatures and class attributes; use `pydantic v2` for data models.
- **No `mypy`**: project uses `basedpyright` only.

## Testing

- Tests live in `tests/` (no tests exist yet — only `app/` and `src/` source).
- `pytest` is configured to skip `integration` marker by default (`-m "not integration"`).
- `asyncio_mode = "auto"` — all async test functions run automatically without `@pytest.mark.asyncio`.
- Coverage reports: `--cov=app` (XML + HTML + terminal). Coverage targets `app/`, not `src/`.
- To run integration tests: `uv run pytest -m integration`.

## Core Development Philosophy

### KISS & YAGNI
- Choose straightforward solutions. Implement only what is currently needed.

### Design Principles
- **Dependency Inversion**: depend on abstractions.
- **Open/Closed**: open for extension, closed for modification.
- **Single Responsibility**: one clear purpose per function, class, module.
- **Fail Fast**: validate early and raise immediately.

### File & Function Limits
- Files: max 500 lines. Functions: max 50 lines. Classes: max 100 lines.

### Architecture (vertical slice)
```
src/project/
    module/
        __init__.py
        logic.py
        tests/
            test_logic.py
```

## Search Commands

Always use `rg` (ripgrep) instead of `grep`/`find`:

```bash
rg "pattern"                    # instead of grep -r
rg --files -g "*.py"            # instead of find . -name "*.py"
```
